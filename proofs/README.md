# proofs/

Stage 1 proofs: each foundation choice is tested for 1–3 days against the quality bar before anything is built on it (briefs in `docs/PROOFS.md`).

One folder per proof, `proofs/<name>/`, with throwaway code and a `README.md`: question, setup, results (full paths to pictures and sound in `C:\Users\Sam\.rostrum\waves\results\stage1\<proof>\`), timings, memory and GPU use, and a verdict (pass / fail / pass with conditions). Proof code is never moved into an app as-is.
