# Rostrum

Four desktop apps for making video — **Rostrum2D**, **RostrumSound**, **Rostrum3D** and **Rostrum Editor** — built so AI agents can do the work and a person can do the same in a simple GUI, aiming at top-tier quality.

**Status:** planning and Stage 1 proofs. No app code yet.
