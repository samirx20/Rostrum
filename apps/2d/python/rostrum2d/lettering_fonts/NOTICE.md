# Single-stroke fonts (paint.letters)

The `.jhf` files here are ten of the Hershey fonts, as packaged (one glyph per line, with a one-line JSON header giving
the cap, base and bottom lines) in the Python package Hershey-Fonts 2.1.0 by apshu (MIT licence,
https://github.com/apshu/HersheyFonts). Only the font data is used; none of that package's code.
